# Earth Savior Reborn

**Earth is under attack.** Pilot an orbital interceptor, blast incoming
asteroids, collect power-ups, and survive escalating waves.

[Get Earth Savior Reborn on Google Play](https://play.google.com/store/apps/details?id=com.ggwp.earthsavior.reborn)

## The game

- Fast-paced arcade space combat
- Touch controls and automatic blasters
- Shields and mega-bomb power-ups
- Increasingly intense asteroid waves
- Local high-score challenge
